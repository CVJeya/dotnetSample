Step 1: Create the database (Neon)
Sign up at neon.com, create a project, and copy the connection string.
Add ?sslmode=require if it isn’t already there.
In your API project, run dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL.


Step 2: Deploy the API on Render
Add a Dockerfile at the API project root:
dockerfile
FROM mcr.microsoft.com/dotnet/sdk:9.0 AS build
WORKDIR /src
COPY . .
RUN dotnet publish -c Release -o /app

FROM mcr.microsoft.com/dotnet/aspnet:9.0
WORKDIR /app
COPY --from=build /app .
ENV ASPNETCORE_URLS=http://0.0.0.0:8080
EXPOSE 8080
ENTRYPOINT ["dotnet", "YourApi.dll"]

Match the .NET version to your project and put your real DLL name in ENTRYPOINT.
2. Push the API to a GitHub repo.
3. In Render, choose New → Web Service, connect the repo, set the runtime to Docker, and select the Free plan.
4. Add environment variables: DATABASE_URL, Jwt__Key (a long random string), and ASPNETCORE_URLS.
5. Deploy, then test https://your-api.onrender.com/api/products.

Step 3: Deploy React on Netlify (no code changes)
Push the React project to GitHub, without node_modules.
On Netlify, choose Add new site → Import from Git, with build command npm run build and publish directory dist.
Add public/_redirects containing these two lines. The first proxies API calls to Render, so your relative /api paths keep working and you need no CORS. The second makes React Router work on refresh.
/api/*  https://your-api.onrender.com/api/:splat  200
/*      /index.html                                200
